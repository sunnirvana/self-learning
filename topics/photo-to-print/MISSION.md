# Mission: 照片到 FDM 可打印模型

## Why
家里有 FDM 打印机，以前只打别人现成的模型。想自己上手：用一张或几张不同角度的照片初步生成三维模型，再调整，最后打印出自己的手办 / 小摆件。

## Success looks like
- 能说清「AI 出模」和「摄影测量」各自适合什么，以及各自会骗人的地方
- 能把一条实物走完：拍照 → 出模 → 检查可打印性 → 修补 → 切片 → 打出一件看得过去的摆件
- 知道 AI/扫描出来的网格为什么常常不能直接打，以及最小修补动作是什么
- 能按「流形 / 尺度 / 壁厚」三件事判断一件模型能不能上机

## Constraints
- 打印机：家用 FDM（耗材机）
- 目标物件：手办 / 小摆件 / 有机造型优先
- 工具：优先选目前最稳、能尽快打出第一件的路径（可含少量付费）；开源路径作备选
- 授课语言：中文

## Out of scope
- 从零手雕 / 全套 CAD 机械设计（功能件、精密配合以后另开课）
- 光固化树脂机的空心、排液、特殊支撑策略
- 游戏资产管线（绑骨、动画、PBR 贴图打磨）
