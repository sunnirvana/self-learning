第一次 AI 出模

目标：STL + 切片报错原文。不要打印。

  1. 本地 clone TripoSR（MIT，免费）
  2. pip install -r requirements.txt（PyTorch 需匹配 CUDA）
  3. python run.py avatar6.jpg --output-dir output/（约 6GB 显存）
  4. 把输出网格导入切片软件（必要时先转 STL）
  5. 记录：报错原文，或「无报错 + 尺寸 mm」
  6. 不要打印；不要和付费的 Tripo Studio / Meshy 网页搞混

背面是预测的。流形检查比网页预览重要。
