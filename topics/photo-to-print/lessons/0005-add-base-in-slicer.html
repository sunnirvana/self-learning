切片里加底座

第 04 课说了「先改打印侧」。这节只做一件事：在切片软件里给 mesh.stl 加一个圆柱底座，合并后重新切片。不换模型、不开 Blender。

完成标志：预览里人物脚下有一块完整底座，整件当作一个物体切片，且仍无报错。打不打由你；先把预览截图贴回来也算过关。

用哪个文件

素材

topics\photo-to-print\TripoSR-main\output\avatar6\0\mesh.stl

先缩放到你习惯的试打高度（如 50–80 mm），再加底座。

Bambu Studio / Orca（推荐路径）

名称以你版本为准：有的叫「组合 / Merge」，有的仍显示「装配」。官方说明见 Bambu Wiki 的 Merge / Stack 与 Assemble；布尔并集见论坛与教程中的 Mesh Boolean → Union。

  1. 导入并放正

    导入 STL → 旋转到脚朝下 → 缩放到目标高度 → 用「放置到面」让底贴床。

  2. 添加圆柱

    在热床空白处右键 → Add Primitive → Cylinder。取消等比缩放：XY 直径比裙摆略大（例如人物投影宽 40 mm 就用 48–55 mm），Z 厚度 2–4 mm。

  3. 对齐到脚下

    推荐：在对象列表里对人物右键 Add part → Cylinder（若有），圆柱会成为同一物体下的 part，可在 Z 向微调，脚底嵌入底座 0.5–1 mm。

    或：圆柱作为独立对象添加后，Ctrl 点选人物 + 圆柱 → 右键 Merge / 组合，再移动 part 对齐。

  4. 真正熔成一体（重要）

    仅 Merge 有时仍是「装配体」，切片可能当两件。选中装配后打开工具栏 Mesh Boolean，选 Union / 并集，变成单个网格。Bambu 文档：装配后用布尔并集才能完全合并。

  5. 再切片检查

    预览层层往下看：底座应是实心盘，脚踝处与底座相连，没有裂缝。支撑优先 Tree/Organic；可加 Brim。

PrusaSlicer 备注

右键热床 → Add Shape → Cylinder；缩放后与模型对齐；多选 → 右键 Merge；若仍是分开的外壳，用 PrusaSlicer 的网格布尔 / 到 Blender 并集后再导入。原则相同：一个连通物体 + 大底面贴床。

怎样算加对了

预览里从底往上看，第一层是完整圆盘；人物脚踝「长在」圆盘上，不是悬浮。若脚踝和底座之间有空气缝，还要再往下嵌一点或做并集。
