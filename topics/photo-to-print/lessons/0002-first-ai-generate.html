第一次 AI 出模

用你的头像立绘走 AI 岔路：生成网格 → 导出 STL → 丢进切片软件 → 读报错，先别按打印。

这节完成的标志只有一个：你手里有一份 STL，并且能说出切片软件对它抱怨了什么（或明确写「没有报错」）。漂亮预览不算完成。

先澄清：谁收费、谁免费

网页商业产品

Meshy、Tripo Studio 等：点几下就出模，但额度 / 订阅要钱。你碰到收费很正常。

开源模型本身

TripoSR（MIT）代码和权重免费；你有 NVIDIA 显卡就可以本地跑，不按次收费。别和同品牌的付费网页搞混。GitHub · 论文 · 官方称单图约需 6GB 显存。

这节主路径改为本地 TripoSR。Meshy 只当你愿意付费换省事时的备选。

操作：本地 TripoSR（免费）

现在不要打第二件、不要开 Blender。按顺序做完即可。命令以仓库 README 为准；若某一步报错，把终端原文贴回来。

  1. 准备环境

    需要：Python ≥ 3.8、已装好的 CUDA、与 CUDA 大版本匹配的 PyTorch（见 pytorch.org）。

  2. 拿到代码

    git clone https://github.com/VAST-AI-Research/TripoSR.git
cd TripoSR
pip install --upgrade setuptools
pip install -r requirements.txt

  3. 对你的头像跑一遍

    把 avatar6.jpg 拷进方便的路径（或写绝对路径）。官方示例是：

    python run.py "D:/BaiduSyncdisk/我的材料/个人材料/avatars/avatar6.jpg" --output-dir output/

    也可用本地界面：python gradio_app.py，在浏览器里上传同一张图。

  4. 找到输出网格

    结果在 output/ 下（常见为 .obj 等）。若暂时没有 STL：先把 OBJ/网格导入切片软件；或下一步用 Blender 另存 STL。名字记清楚。

  5. 丢进切片软件，读报错

    Bambu Studio / Orca / PrusaSlicer / Cura 任一即可。导入后先看：

    • 有没有 non-manifold / 破面 / 修复提示？
    • 预览里有没有乱飘的碎面、薄片？
    • 默认尺寸是否离谱？记下毫米数，先别打。

    不要按打印。作业是「读懂抱怨」，不是「打出成品」。

卡在安装时

官方常见坑：torchmcubes 没编上 CUDA。按 Troubleshooting 重装即可。显存不够就关其它占 GPU 的程序；仍不够再告诉我显卡型号。

以后若要更好看、更重的开源模型，可以再试 Hunyuan3D / TRELLIS——也是本地免费，但安装更重，不作为第一次作业。

和第 01 课对齐

你现在停在流水线的第 3–4 步：出模 + 检查可打印性。第 5 步「修补」下一课再练。屏幕上转得好看 ≠ 切片认为它是封闭物体。
