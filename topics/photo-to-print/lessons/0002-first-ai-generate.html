第一次 AI 出模

用你的头像立绘走 AI 岔路：生成网格 → 导出 STL → 丢进切片软件 → 读报错，先别按打印。

这节完成的标志只有一个：你手里有一份 STL，并且能说出切片软件对它抱怨了什么（或明确写「没有报错」）。漂亮预览不算完成。

推荐工具

主路径：Meshy Image to 3D

上手快，支持导出 STL，面向打印的文档多。免费账号通常够做第一次。步骤综合自 Meshy 教程：Image to 3D Guide、Photo to printable。界面若改版，以网站实际按钮为准。

备路径：TripoSR Demo

开源单图重建演示，适合理解「它在预测」。导出后往往更糙，仍要进切片检查。HF Space；论文 arXiv:2403.02151。

这节默认走 Meshy。若你更想完全免费开源，用 TripoSR，步骤末尾同样：导出 → 切片 → 读报错。

操作：对着网站点

现在不要打第二件、不要开 Blender。按顺序做完下面五步即可。

  1. 打开 Image to 3D

    注册 / 登录 meshy.ai，进入 Image to 3D（侧栏或功能页）。

  2. 上传 avatar6.jpg

    选单图上传。若提示可选多视角而你只有这一张，就只用这一张继续——我们接受背面是预测。

  3. 生成，可选用 Refine

    先出 Preview 也行。若有 Refine / 类似「细化、修面」选项，第一次建议开：商业文档称它有助于补洞，但仍不能代替你自己的切片检查。

  4. 导出 STL

    在 Download 里选 STL（不是只下 GLB）。STL 是 FDM 切片最常见入口之一。记下文件名，例如 avatar6.stl。

  5. 丢进你的切片软件，读报错

    Bambu Studio / Orca / PrusaSlicer / Cura 任一即可。导入后先看：

    • 有没有 non-manifold / 破面 / 修复提示？
    • 预览里有没有乱飘的碎面、薄片？
    • 默认尺寸是否离谱（巨大或指甲盖大）？先别急着打，记下毫米数。

    不要按打印。这节的作业是「读懂抱怨」，不是「打出成品」。

和第 01 课对齐

你现在停在流水线的第 3–4 步：出模 + 检查可打印性。第 5 步「修补」下一课再练。屏幕上转得好看 ≠ 切片认为它是封闭物体。

练：确认你没走岔

回忆 3 / 3

单张正面立绘生成后，背面几何从哪来？

答完会在这里计分。

作业（贴回来就能进下一课）：

  1. 你用的工具名（Meshy / TripoSR / 其他）
  2. 切片软件名
  3. 它说了什么：把报错原文或截图描述贴上；若完全没有报错，写「无报错」，并告诉我导入后模型大概多大（毫米）
