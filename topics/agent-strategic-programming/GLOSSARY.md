# 战术式编程 / 战略式编程 Glossary

本工作区只使用 Ousterhout 第 3 章的用语。迁到 agent 时必须标明是类比。

## Terms

**战术式编程**:
以「让下一项能工作」为首要目标的工作方式。
_Avoid_: 战术性设计, 战术设计（DDD 用语）

**战略式编程**:
以「做出好设计，碰巧也能工作」为首要目标的工作方式。
_Avoid_: 战略性设计, 战略设计（DDD 用语）

**首要目标**:
一次工作真正在优化的那件事，不是附带完成的那件事。

**投资**:
多花的、用来让系统以后更好改的时间；量级约 10%–20%，持续投入，不是一次设计完整个系统。

**战术式飓风**:
出活极快、留下别人必须收拾的复杂度的人（或用法）。
