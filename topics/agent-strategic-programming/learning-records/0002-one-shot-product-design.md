# 能识别「产出满意、方法没沉淀」是战术式

用户用自己的 agent 工作对上了第 01 课的尺子：做产品设计时追求一次出完、产出物满意，但没有抽出下次还能用的方法，再做同类工作时只能重写 prompt。这说明他们已经能把「能工作」和「系统更好改」拆开，不再把满意的答卷误当成战略式。

## Implications

- 下一课不要再讲对立心态的定义，改为练最小战略动作：一次做完之后，切开「这一次」和「下一次还要的方法」。
- 澄清两件容易混的事：第一次从零写 prompt 是可以的（设计第一次很难对）；重复时还从零写，才是继续战术式。
- 等用户带回一张从真实产品设计里抽出的方法卡片，再考虑把「抽出方法」写入术语表。
