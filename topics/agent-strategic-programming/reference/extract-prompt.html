对着旧对话抽方法

五步：打开已满意的对话 → 发提取提示 → 踢实例 → 存五栏 → 下次只填新实例。

  1. 在产出满意稿的那次会话里继续。找不到就把终稿加要求贴进新会话，仍不要再设计。
  2. 发出提取提示。禁止它改稿。
  3. 换一个产品仍成立的留下；产品名、用户、视觉、轶事踢出。
  4. 只存五栏，不存整次对话。
  5. 下次：粘贴方法 + 这一次的输入。
